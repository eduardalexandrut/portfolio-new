# Personal Portfolio 🚀

Welcome to the repository for my personal portfolio website!

I am a Software Engineer with a deep interest in Computer Vision, AI, and UAV autonomy. This static website serves as my digital "flight log", showcasing my academic background, technical skills, and latest projects.

## 🌐 Live Website

You can view the live version of the portfolio deployed via GitHub Pages here:  
👉 **[https://eduardalexandrut.github.io/portfolio-new/](https://eduardalexandrut.github.io/portfolio-new/)**

## 🛠️ Tech Stack

This project is intentionally built without heavy frameworks to keep it fast, lightweight, and fully customized:
- **HTML5 & CSS3:** Custom styling, CSS Grid/Flexbox, and native keyframe animations (radar, orbits).
- **Vanilla JavaScript:** Dynamic project rendering and keyword filtering using a local JSON file.
- **GitHub API:** Fetches and displays recent push activity dynamically.
